# Etsy Video Generator

One-page Next.js app that turns 2–10 product photos into an Etsy listing video **entirely in the browser**. Images never leave the tab.

## Motion presets (Alura-style)

- **Gentle Reveal** — slow scale / Ken Burns zoom with a soft crossfade
- **Scale In** — each photo grows in, then the next lands on top
- **Gallery Glide** — continuous sideways pan through every photo
- **Rapid Showcase** — fast punch-in cuts

Output matches Etsy’s listing video rules: 5–15 seconds, 1080px+, MP4, no audio.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Chrome or Edge recommended for MP4 export.
